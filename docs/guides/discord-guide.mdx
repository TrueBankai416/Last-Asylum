# Discord Guide

Welcome to **The Last Asylum** Discord! This guide walks you through everything you need to know — roles, channels, permissions, and how to use our bots.

:::tip[First Time Here?]
Head to **#welcome** and accept the rules to gain server access. Then visit **#get-roles** to pick up optional roles.
:::

## Roles

Roles are listed from highest to lowest authority.

| Role | Icon | Description |
|------|------|-------------|

## Bot Commands Reference

:::note[Officers Only]
The **#bot-commands** channel is restricted to Officers+. The commands below are for reference.
:::

### Carl-bot *(prefix: `!`)*

#### Moderation

| Command | Description |
|---------|-------------|
| `!ban @member [days] [reason]` | Permanent ban |
| `!tempban @member [days] [dur] [reason]` | Timed ban |
| `!softban @member [days] [reason]` | Ban/unban to clear message history |
| `!massban @member... [days]` | Ban multiple members at once |
| `!kick @member [reason]` | Kick a member |
| `!mute @member [duration] [reason]` | Mute a member |
| `!hardmute @member [dur] [reason]` | Mute + strip all roles |
| `!unmute @member [reason]` | Remove a mute |
| `!timeout @member [time] [reason]` | Discord timeout |
| `!removetimeout @member [reason]` | Remove a timeout |
| `!warn @member [reason]` | Issue a warning |

#### Warnings

| Command | Description |
|---------|-------------|
| `!warns [@member]` | List warnings for a member |
| `!removewarn <case_id>` | Remove a warning by case ID |
| `!clearwarn @member` | Clear all warnings for a member |

#### Lockdown

| Command | Description |
|---------|-------------|
| `!lockdown [#channel] [duration]` | Lock a channel |
| `!unlockdown [#channel]` | Unlock a channel |
| `!lockdown server [duration]` | Lock the entire server |
| `!unlockdown server` | Unlock all channels |

#### Purging

| Command | Description |
|---------|-------------|
| `!purge [#] [@member]` | Purge messages or messages by a user |
| `!purge bot [#] [prefix]` | Purge bot messages |
| `!purge contains [#] <text>` | Purge messages containing a keyword |
| `!purge links [#]` | Purge messages with links |
| `!purge images [#]` | Purge images & embeds |
| `!cleanup [#]` | Purge Carl-bot's own messages |

#### User Notes

| Command | Description |
|---------|-------------|
| `!setnote @member <note>` | Add a note to a member |
| `!notes @member` | View all notes for a member |
| `!removenote <note_id>` | Remove a note by ID |
| `!clearnotes @member` | Clear all notes for a member |

#### Utility

| Command | Description |
|---------|-------------|
| `!info [@member]` | User info & roles |
| `!serverinfo` | Server stats |
| `!setnick @member <name>` | Change a user's nickname |
| `!report <message>` | Send a message to the report channel |
| `!reportchannel #channel` | Set the report channel |
| `!poll <question,opt1,opt2>` | Create a reaction poll |
| `!rm <when> [about]` | Set a reminder |

### Timely *(timezone conversion)*

Wrap any time in backticks and Timely will reply with a Discord timestamp that each user sees in **their own local time**.

```
`3:30 PM EST`    `8:30 PDT`    `1300 CET`    `7:30 UTC`
`1AM (London)`   `12:30 Vancouver`
```

:::caution
24-hour times must be **4 digits** — e.g. `` `0800 EST` `` not `` `800 EST` ``.
:::

Use `/timely` to set your personal timezone & locale so you can omit the timezone from future conversions, e.g. `` `3 PM` ``.
